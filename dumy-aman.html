Peringatan: mode ini sengaja rentan untuk praktikum; jangan gunakan di layanan nyata. Aksi yang terdeteksi hanya disimulasikan dan tidak menjalankan tool sungguhan.

Privasi: API key hanya disimpan di sessionStorage pada tab ini dan dikirim langsung dari browser ke Google AI. Jangan masukkan key milik orang lain, data pribadi, atau rahasia. Hapus key dengan menutup tab.
